# `task append-metrics-session`: the append verb and the refusal of the generic write verbs

<summary>
- A new vault-cli verb records one Claude session against a task, so a session connected outside `vault-cli task work-on` still lands in that task's metrics.
- The verb appends to whatever the task already holds: existing entries survive untouched and in their original order.
- The entry it writes is the same shape the older `task work-on` path writes, so the two producers feed one corpus rather than two lookalikes.
- `task set`, `task add` and `task remove` now refuse the metrics field with a message that names the field and points at the new verb, instead of writing a value every reader silently discards.
- A session id that is empty, not a UUID, or carries a path separator is refused before anything is read or written.
- The task file is byte-identical after every refused write.
- The session-id field and its write path are untouched; the new verb never writes it.
- Nothing reads differently: the interaction counter, the completion timestamps, the cycle archive and the auto-resume gate behave exactly as before.
- Adds no flag, no config key and no new dependency.
</summary>

<objective>
Add the `vault-cli task append-metrics-session <task-name> <session-id>` verb — an ops operation that appends exactly one `{session_id, started_at}` entry through the existing domain append, plus its CLI registration — and make `task set` / `task add` / `task remove` refuse the `metrics_sessions` field before any mutation. This is the write path the plugin's session-connect step will call in prompt 2; without it a fleet-spawned worker's run stamps its session id and lands no metrics entry, which is the defect the spec exists to close.
</objective>

```go
// AppendMetricsSessionOperation appends one metrics entry to a task.
//
//counterfeiter:generate -o ../../mocks/append-metrics-session-operation.go --fake-name AppendMetricsSessionOperation . AppendMetricsSessionOperation
type AppendMetricsSessionOperation interface {
	Execute(ctx context.Context, vaultPath, taskName, sessionID string) error
}

// NewAppendMetricsSessionOperation creates a new append-metrics-session operation.
func NewAppendMetricsSessionOperation(
	taskStorage storage.TaskStorage,
	currentDateTime libtime.CurrentDateTime,
) AppendMetricsSessionOperation {
	return &appendMetricsSessionOperation{
		taskStorage:     taskStorage,
		currentDateTime: currentDateTime,
	}
}

type appendMetricsSessionOperation struct {
	taskStorage     storage.TaskStorage
	currentDateTime libtime.CurrentDateTime
}

// Execute validates the session id, then appends exactly one entry to the task's
// metrics_sessions, preserving every entry already present. started_at is stamped
// here from the injected clock; no caller supplies it.
//
// The id is validated before the task is read, so an id this verb cannot honour is
// refused with nothing read and nothing written. The entry goes through the domain
// append (domain.TaskFrontmatter.AppendMetricsSession) — the same writer the
// work-on path uses — so the two producers emit one shape.
//
// There is deliberately no re-read, no lock and no dedup: the spec accepts the same
// last-write-wins race the work-on path has, and the accumulator must never suppress
// a duplicate session id.
func (o *appendMetricsSessionOperation) Execute(
	ctx context.Context,
	vaultPath, taskName, sessionID string,
) error {
	if err := uuid.Validate(sessionID); err != nil {
		return errors.Wrapf(ctx, validation.Error,
			"invalid session id %q: expected a well-formed UUID", sessionID)
	}
	task, err := o.taskStorage.FindTaskByName(ctx, vaultPath, taskName)
	if err != nil {
		return errors.Wrap(ctx, err, "find task")
	}
	task.AppendMetricsSession(domain.MetricsSession{
		SessionID: sessionID,
		StartedAt: libtime.DateOrDateTime(o.currentDateTime.Now().Time()),
	})
	if err := o.taskStorage.WriteTask(ctx, task); err != nil {
		return errors.Wrap(ctx, err, "write task")
	}
	return nil
}
```

Non-negotiable properties:

- **The guard runs first.** `uuid.Validate(sessionID)` is the first statement, before `FindTaskByName`. An unhonourable id therefore reads nothing and writes nothing.
- **`uuid.Validate`, not a hand-rolled check.** `github.com/google/uuid` v1.6.0 (already in `go.mod`) exports `Validate(s string) error`; it rejects the empty string, a non-UUID string, and any value carrying a newline or a path separator. Do NOT write a regex, a length check, or a `uuid.Parse` plus discard.
- **The error names the required shape.** The message is exactly `invalid session id %q: expected a well-formed UUID`, wrapped with `errors.Wrapf(ctx, validation.Error, …)` so it is a validation-class error and NOT `storage.ErrNotFound`-class. That matters: `ops.VaultDispatcher.FirstSuccess` continues to the next vault only on an `ErrNotFound`-class error, so a guard error must abort the dispatch rather than be retried across every vault.
- **The append is the domain append.** Call `task.AppendMetricsSession(...)`; do NOT build the list by hand, do NOT call `task.Set("metrics_sessions", …)`, and do NOT call `AppendMetricsSession` with an empty `SessionID` (it silently ignores such an entry, which would make the guard above unreachable-looking).
- **`started_at` comes from the injected clock**: `libtime.DateOrDateTime(o.currentDateTime.Now().Time())`. Do NOT call `time.Now()` directly, and do NOT accept a timestamp parameter.
- **One read, one write.** `FindTaskByName` then `WriteTask`. Do NOT re-read before writing, do NOT take a lock, do NOT retry, and do NOT add an "already recorded" guard.
- The struct is unexported and the constructor returns the interface, per `go-factory-pattern.md`.

```go
// metricsSessionsWriteRefusal returns an error when a generic write verb
// (set / add / remove) targets metrics_sessions on a task.
//
// The field's entries are maps (session_id + started_at). `set` stores whatever
// string it is handed, and `add` / `remove` comma-split their value into a list of
// scalars; the dedicated list reader discards both shapes by design, so either verb
// would report success while recording nothing visible. The append goes through
// `vault-cli task append-metrics-session <task> <session-id>`.
//
// Nothing is written on the refusal path: the check runs before any mutation, so the
// file on disk is byte-identical. There is no --force bypass — --force is scoped to
// the phase-regression guard, and this refusal is deliberately absolute.
func metricsSessionsWriteRefusal(ctx context.Context, taskName, key string) error {
	if key != "metrics_sessions" {
		return nil
	}
	return errors.Errorf(ctx,
		"cannot write %q on %q with this verb: metrics_sessions entries are maps (session_id + started_at) and every reader discards a scalar or a comma-split list. Append an entry with `vault-cli task append-metrics-session %q <session-id>`",
		key, taskName, taskName,
	)
}
```

Non-negotiable properties:

- **The message names the field and the verb.** The rendered error contains the literal `metrics_sessions` and the literal `append-metrics-session`; spec AC 4 greps stdout/stderr for both.
- **One definition, two call sites.** Do NOT inline a second copy of this message in either call site, and do NOT add a second refusal helper.
- **Scope is the task family only.** Both call sites are task-only operations. Do NOT wire this into `goalSetOperation`, `topicSetOperation`, `themeSetOperation`, `objectiveSetOperation`, `visionSetOperation`, or any `*TagsListOperation` — the spec's Desired Behavior 4 names `task set`, `task add` and `task remove` and nothing else.

```go
//nolint:dupl,gocognit,nestif // Mutation commands have similar structure but different operations
func createTaskAppendMetricsSessionCommand(
	ctx context.Context,
	configLoader *config.Loader,
	vaultName *string,
	outputFormat *string,
) *cobra.Command {
	return &cobra.Command{
		Use:   "append-metrics-session <task-name> <session-id>",
		Short: "Append one metrics_sessions entry to a task",
		Args:  cobra.ExactArgs(2),
		RunE: func(cmd *cobra.Command, args []string) error {
			taskName := args[0]
			sessionID := args[1]

			vaults, err := getVaults(ctx, configLoader, vaultName)
			if err != nil {
				return errors.Wrap(ctx, err, "get vaults")
			}

			dispatcher := ops.NewVaultDispatcher()
			err = dispatcher.FirstSuccess(ctx, vaults, func(vault *config.Vault) error {
				storageConfig := storage.NewConfigFromVault(vault)
				appendOp := ops.NewAppendMetricsSessionOperation(
					storage.NewTaskStorage(storageConfig),
					libtime.NewCurrentDateTime(),
				)
				return appendOp.Execute(ctx, vault.Path, taskName, sessionID)
			})
			if err != nil {
				if OutputFormat(*outputFormat).IsJSON() {
					return PrintJSON(map[string]any{
						"success": false,
						"error":   err.Error(),
					})
				}
				return err
			}
			if OutputFormat(*outputFormat).IsJSON() {
				return PrintJSON(map[string]any{
					"success":    true,
					"name":       taskName,
					"session_id": sessionID,
				})
			}
			fmt.Printf("✅ Appended metrics session %s to: %s\n", sessionID, taskName)
			return nil
		},
	}
}
```
